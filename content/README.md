# content/

Aquí vive el contenido de cada certificación como archivos tipados (`content/<clave>/`): fases, retos, teoría, glosario, duelos y rondas. Lo edita solo la administradora (ADR-0002).

La primera certificación será «Periodo de Tiempo» (`content/tiempo/`, hito H2). Las claves de respuesta de las actividades calificadas irán separadas del contenido que llega al navegador (ADR-0004).
