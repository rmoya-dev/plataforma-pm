# ADR-0007 — Alcance: solo el curso de Pensamiento Matemático

- **Estado:** Aceptada (aprobada por la responsable el 2026-11-21)
- **Fecha:** 2026-11-21
- **Decide:** Flor Tapia

## Contexto
Hay otras iniciativas de la responsable (tutor APA, AulaSegura, SARA, cursos en Notion) que no pertenecen a este curso.

## Decisión
La plataforma es solo para Pensamiento Matemático. Otras iniciativas del curso (Tutor PM, juego de los bancos) se agregan como módulos.

## Alternativas consideradas
Una plataforma general para todas las iniciativas (dispersa el alcance).

## Consecuencias
Una arquitectura de módulos (RF-11) para sumar recursos del curso sin tocar el motor.
